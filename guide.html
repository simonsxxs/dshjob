Skill 技能包

适合谁

已经有顺手的 AI 工具，想给它添加一个「找工作」技能的人。

Skill（技能包）是打包好的技能说明，AI 工具读取后就会按里面的流程帮你搜集岗位、筛选机会、拟稿和记录进度。这不是安装一个新软件，和上面「软件下载」是两种不同的使用方式。

Skill 技能包已发布，可以从 GitHub 或 Gitee 免费获取（见下方按钮）。开始前请花一分钟了解它的安全原则：默认全程「干跑」——采集、筛选、拟稿、记录都会真实执行，但一条消息都不会发出去，真实发送需要你对每个平台单独授权；遇到验证码或安全提示会立刻停下来交给你处理；登录、扫码永远由你本人完成；每天的操作数量和时段都有上限，保护你的账号。

准备条件

  • 一台 macOS 或 Windows 电脑——工具在你的电脑上运行，本网站不代为运行。
  • Chrome 浏览器：工具驱动的是你日常使用的 Chrome，复用你的登录状态。
  • Python 3.8 或更高版本（一种常用的编程语言运行环境）：macOS 系统自带；Windows 请到 python.org 下载，安装时记得勾选「Add to PATH」（把 Python 加入系统路径）。
  • kimi-webbridge 浏览器扩展和它的本地服务：这是 AI 和 Chrome 之间的「桥」，智能体通过它操作浏览器。
  • 一款支持 AGENTS.md 约定的 AI 智能体（如 ZCode、Claude Code、Kimi 等），用来读取项目并按技能说明操作。
  • 各招聘平台的账号：自己注册、自己登录。

覆盖平台：BOSS 直聘（采集、打招呼、聊天回复，流程最完整）、智联招聘（采集、打招呼拟稿、聊天采集与草拟）、前程无忧 51JOB（采集、投递拟稿）、鱼泡直聘（采集、打招呼拟稿）、猎聘（采集、打招呼拟稿，节奏最保守）。所有平台的沟通拟稿默认都不自动发送。

操作位置

全部在你自己的电脑上完成：Chrome 负责打开招聘平台，智能体负责按技能说明执行，本网站不参与运行。

第一次使用

  1. 获取技能包：从下面两个仓库之一，把项目下载到你的电脑并解压。

    查看 GitHub 仓库 查看 Gitee 仓库

  2. 装桥：给 Chrome 安装 kimi-webbridge 扩展，并在电脑上启动它的本地服务。
  3. 登录：在 Chrome 里手动登录你要用的招聘平台，扫码、验证码都由你本人完成。
  4. 把项目交给智能体：用你的 AI 智能体打开项目所在的文件夹，直接说一句「帮我跑一轮 BOSS 采集」。它会先读项目说明和安全规则，再引导你补充搜索关键词和城市；首次使用会创建你的「人设档案」（你的简历和求职意向，只保存在你自己的电脑，不上传任何云端）。
  5. 想先确认环境装对了？让智能体跑一遍自测，全部通过就说明就绪。

请先阅读这个项目的使用说明，检查运行条件，再引导我补充求职需求。先执行筛选、拟稿和记录，不发送消息、不投递简历；需要登录或授权时停下来告诉我。完成后告诉我在哪里查看结果。

默认干跑：筛选、拟稿、记录会真实执行，但不会自动发出消息或投递简历；需要登录或授权时会停下来等你确认。

结果在哪看

所有岗位记录都保存在你自己的电脑上，并自动生成一个本地网页看板：双击项目里「看板数据」文件夹中的「求职看板.html」，用浏览器打开就能看到岗位、拟稿和进度；每次有新的记录，看板会自动刷新。

下载失败

下一步：换另一个仓库来源重试（GitHub 与 Gitee 互为备用），或复制仓库链接，等网络可用时在电脑上再试。

找不到入口

下一步：回到首页获取工具区域，按「软件下载 / Agent 智能体 / Skill 技能包 / MCP 工具接入」四张卡重新选择，再进入对应教程章节。

环境缺失

下一步：把 Agent 或工具提示的缺项原样记下来，按提示补装缺的组件；不确定缺什么时，带着提示文字联系 simon。

首次运行失败

下一步：回到对应章节的「第一次使用」，逐步核对每一步是否完成；仍失败时记下报错文字（不要包含密码、简历等隐私），再联系 simon。

没有结果

下一步：先检查筛选条件是否太严、对应平台账号是否已登录，再按「结果在哪看」重新确认位置；空结果也是真实结果，不代表工具坏了。

需要人工接管

下一步：登录、扫码、验证码和真实发送都需要你本人完成；工具停下来等确认时，按提示在对应平台操作，完成后再让 AI 继续。
