## Purpose

定义 dshjob 面向 AI 新手的免费静态官网首版行为，使访客能理解用途、选择软件下载或 Agent / Skill / MCP 方式、找到真实获取入口及对应教程，并在卡住时联系作者。所有功能在静态页面范围内完成，求职任务在用户自己的工具环境运行。

## ADDED Requirements

### Requirement: WEB-01 静态官网与内容边界

网站 MUST 使用无需构建的 HTML / CSS / JavaScript 提供首页和教程；MUST 明示免费项目定位、实际运行位置和工具准备条件。网站 MUST NOT 接入求职账号、上传简历、调用本地 Agent、显示虚构实时求职数据或设置站内付费流程。

#### Scenario: 新访客理解用途
- **WHEN** 访客打开首页
- **THEN** 首屏可读项目用途、“免费获取工具”和“查看使用教程”，并能得知工具在自己的电脑环境中使用。

#### Scenario: 脚本不可用
- **WHEN** JavaScript 被禁用或初始化失败
- **THEN** 首页正文、四种方式、已知外链、教程和微信号仍可读可访问；页面不要求等待脚本或登录。

### Requirement: WEB-02 页面与导航

网站 MUST 提供 `index.html`、`guide.html` 及最小 `404.html`；首页 MUST 包含 `features`、`demo`、`start`、`downloads`、`faq`、`contact` 锚点，教程 MUST 包含 `software`、`agent`、`skill`、`mcp`、`help` 章节。固定导航不得遮挡锚点标题。

#### Scenario: 首页进入教程
- **WHEN** 访客点击某种方式的“查看教程”
- **THEN** 到达 `guide.html` 对应章节，浏览器返回可回到来源页面，教程提供首页和获取区返回入口。

#### Scenario: 手机菜单
- **WHEN** 手机用户用点击或键盘打开菜单、选择条目或按 Escape
- **THEN** 展开状态与 `aria-expanded` 一致，选择后关闭并到达目标；Escape 关闭并将焦点放回按钮，菜单不导致横向溢出。

#### Scenario: 找不到页面
- **WHEN** 静态托管收到不存在的页面路径
- **THEN** 展示清楚的 404 说明和回到首页 / 教程的入口，不伪装为已找到内容或启动单页应用路由。

### Requirement: WEB-03 四种使用方式

获取区 MUST 按“软件下载、Agent 智能体、Skill 技能包、MCP 工具接入”顺序展示四卡；每卡 MUST 有适合谁、准备条件、当前状态、仓库入口和独立教程。软件下载 MUST 与交给已有 Agent 使用项目的方式区别说明。

#### Scenario: 新手比较方式
- **WHEN** 用户查看获取区
- **THEN** 可以直接阅读四种方式，无须理解术语才能看到软件下载，且安装包未就绪时不显示“推荐下载”或“开箱即用已验证”。

#### Scenario: 手机排列
- **WHEN** 页面宽度在 360 或 390 CSS 像素
- **THEN** 四卡按相同顺序单列展示，按钮完整且不依赖悬停，软件下载卡不会覆盖其他方式。

### Requirement: WEB-04 软件安装包状态

软件卡 MUST 按已确认系统 / 架构展示对应条目。只有版本、包名、更新日期、大小、至少一个真实来源和对应教程均核实后，条目才能为可获取；未确认信息 MUST 使用准备状态，不得从用户代理字符串推断已支持的系统。网站 MUST NOT 将源码压缩包称为软件安装包。

#### Scenario: 安装包准备中
- **WHEN** 尚未提供系统或安装包地址
- **THEN** 显示“安装包准备中”和待确认的信息，保留两个项目仓库与软件教程入口，不渲染可点击的假下载链接。

#### Scenario: 下载版本可用
- **WHEN** 一个系统 / 架构版本和来源已验证
- **THEN** 页面标明系统、架构、版本、包信息，点击已核实来源进入准确的包或发布页面；无需登录官网或提供个人信息。

#### Scenario: 部分来源缺失
- **WHEN** 同一版本在一个来源已核实，另一个来源未提供或不可用
- **THEN** 只提供有效来源的安装包链接，另一来源显示准备中或当前不可用；保留“查看 Gitee 仓库”和“查看 GitHub 仓库”，不以源码地址替代缺失安装包。

#### Scenario: 多平台或版本选择
- **WHEN** 存在多个已确认的软件条目
- **THEN** 用户可手动查看并选择系统 / 架构，选择只切换可见信息，不自动下载、安装、打开本地应用或声称下载成功；手机提示到支持的电脑使用。

### Requirement: WEB-05 真实获取链接与故障出口

网站 MUST 使用用户给定的 Gitee / GitHub 项目入口，并将仓库链接与真实发布物链接分开维护。未知 URL MUST 不生成链接或 `href="#"` 占位。外链 MUST 有易懂名称，新窗口需标明且使用 `rel="noopener noreferrer"`。不做客户端定时探测、重试下载或代理下载。

#### Scenario: 仓库只有源码
- **WHEN** 已知地址未核实到对应工具发布物
- **THEN** 按钮标为“查看仓库”，资料状态清楚说明待补齐；不能标为下载完成或已可运行。

#### Scenario: 用户无法访问外站
- **WHEN** 用户遇到外部来源访问问题
- **THEN** 卡片原有另一来源和教程求助说明仍可找到；页面不需要检测对方网站错误才能提供备用入口。

### Requirement: WEB-06 连续上手教程

教程 MUST 为四种方式分别说明适合谁、系统与环境、获取入口、打开 / 接入位置、首次需求、结果位置和错误出口。软件章节 MUST 以实际安装向导说明为依据；未知条件不能编造成操作步骤。真实发送、登录和验证码由用户本人处理，官网只解释流程。

#### Scenario: 使用软件教程
- **WHEN** 用户进入软件章节且材料已齐
- **THEN** 可按系统与包版本完成“获取 → 安装 / 打开 → 准备 → 首次需求 → 看结果”的连续指引，截图和名称匹配发布物。

#### Scenario: 教程材料缺失
- **WHEN** 某方式尚未核实安装或接入条件
- **THEN** 显示已知条件、准备状态及仓库 / 联系入口，不出现猜测命令、虚构路径或未证明的“零配置”。

#### Scenario: 第一次让 Agent 做事
- **WHEN** 用户阅读或复制首次需求示例
- **THEN** 文案说明先筛选、拟稿和记录，不发送消息或投递；同时说明采集与记录可能实际发生。复制行为不会自动把指令发给 Agent。

### Requirement: WEB-07 演示与 FAQ

演示 MUST 使用始终标注“演示数据”的虚构内容，提供“说出需求 / 查看岗位 / 查看进度”三视图；默认有完整可见内容，无自动轮播。FAQ MUST 覆盖费用、运行位置、四种方式、平台差异、准备条件、真实发送、手机、数据和求助。

#### Scenario: 切换演示
- **WHEN** 用户点击或按键选择演示视图
- **THEN** 当前视图及控件状态一致，焦点可辨；示例不增加伪造的实时进度，不造成明显页面跳动。

#### Scenario: 无脚本阅读 FAQ 和演示
- **WHEN** 脚本未运行
- **THEN** FAQ 可通过原生展开阅读，三个示例以普通内容顺序保留，重要信息不因隐藏面板而丢失。

### Requirement: WEB-08 联系与复制反馈

首页和教程 MUST 显示 simon、微信 `simonsxxs` 与用户提供的二维码原图；二维码 MUST 保持比例和完整边界，不重绘或动画处理。复制微信号、仓库 URL 或提示语 MUST 仅在剪贴板写入成功后提示“已复制”，失败时提供可选择文字和手动方法。

#### Scenario: 图片失败与大图
- **WHEN** 二维码失败或用户需要更大的图片
- **THEN** 文字微信号仍可用；有效原图提供查看大图链接，无需弹窗、提交资料或依赖扫码。

#### Scenario: 剪贴板成功或拒绝
- **WHEN** 用户点击复制且剪贴板成功或被拒绝
- **THEN** 成功显示短暂可感知反馈；拒绝 / 不支持 / 文件协议限制时不误报，显示手动选择复制提示。

### Requirement: WEB-09 浅色视觉与响应式

网站 MUST 以已确认 v2 为视觉基线，使用浅雾蓝背景、白卡、深蓝文字和蓝青色光束，全站不设置黑底区块。正文不少于 16px、行距不少于 1.6，普通文字对比度不少于 4.5:1；主要触控目标不小于 44×44px。

#### Scenario: 响应式和放大
- **WHEN** 在 360、390、768、1440、1920 CSS 像素宽度或 200% 缩放下浏览
- **THEN** 不出现正文横向溢出、被裁切按钮或固定屏高截断；卡片、演示和教程按空间重排。

#### Scenario: 键盘与焦点
- **WHEN** 用户只使用键盘
- **THEN** 可跳到正文，依次使用导航、演示、下载、FAQ、复制与动效开关；焦点不被装饰层覆盖，菜单关闭后不困住焦点。

### Requirement: WEB-10 粒子光束与运行状态

首页 MUST 有可辨识的弧形蓝青光束及沿束流动的粒子，桌面鼠标只轻微影响装饰，正文和按钮不移动。向正文滚动时光束弱化，离开首屏停止绘制。教程和二维码区域 MUST 无持续背景运动，装饰不接收点击。

#### Scenario: 正常桌面或手机运行
- **WHEN** 首页可见、首屏在视口且允许动效
- **THEN** 桌面平缓流动并有不超过 8px 鼠标响应；手机使用更低密度与分辨率，不要求悬停，背景最多一个动画循环。

#### Scenario: 隐藏或离开首屏
- **WHEN** 页面隐藏或首屏完全离开视口
- **THEN** 停止动画计算；回到可见首屏时仅在未暂停、无系统减少动态且无失败锁定的条件下恢复。

### Requirement: WEB-11 暂停与静态回退

网站 MUST 提供键盘可用的“暂停动效 / 开启动效”，并尊重系统 `prefers-reduced-motion`。减少动态时 MUST 关闭粒子循环、鼠标响应、入场位移和平滑滚动。初始化失败、上下文丢失或持续低性能 MUST 回退到完整浅色静态光束，不阻塞内容。

#### Scenario: 用户暂停后切换页面可见性
- **WHEN** 用户暂停后隐藏再显示浏览器页面
- **THEN** 动效保持暂停，按钮状态真实，不自行恢复。

#### Scenario: 系统减少动态效果
- **WHEN** 系统设置减少动态效果，包括页面打开后改变设置
- **THEN** 立即采用静态样式；点击页面开关不能覆盖系统设置强制开启动效，保留用户原有暂停偏好。

#### Scenario: 图形失败或性能降档
- **WHEN** 无 Canvas 2D、初始化抛错、上下文丢失，或最低档仍达不到预算
- **THEN** 取消循环并保留静态光束、完整内容和有效链接；本页不无限尝试重新初始化。

### Requirement: WEB-12 本地运行与性能预算

网站 MUST 在本地文件打开和静态 HTTP 托管下阅读、导航及查看资源，不依赖 `fetch` 加载核心内容或 ES 模块服务器。首屏文字不得等待动效。按 design 固定方法验收核心 HTML / CSS / JS 压缩总量 ≤300KB、首屏总资源 ≤1MB，移动实验室 LCP ≤2.5s、CLS ≤0.1；桌面目标 ≥50fps，手机目标 ≥30fps，失败则降档或静态回退。

#### Scenario: 双击文件访问
- **WHEN** 用户直接打开 `index.html` 或 `guide.html`
- **THEN** 相对链接、图片、正文、FAQ 正常；复制受限时提供手动出口，不调用本地端口或要求 npm 安装。

#### Scenario: 性能验证
- **WHEN** 实施方完成性能验收
- **THEN** 记录设备、系统、浏览器完整版本、网络、采样方法和原始结果；未测试设备标为未验证，不能把手机模拟视口当真实手机帧率。

### Requirement: WEB-13 公开内容和搜索元数据

每个正式内容页 MUST 有独立中文 title、description、单个 H1 和正确语言声明；公开素材 MUST 为虚构示例或经确认可公开资料，不含本机绝对路径、密钥或真实求职记录。免费公开不等于特定开源许可证或所有模型免费。

#### Scenario: 正式 URL 与索引
- **WHEN** 获准发布并核实正式域名
- **THEN** 首页 canonical 为 `https://dshjob.com/`，教程为托管实际规范路径 `/guide`；sitemap 只包含这两个内容页，404 标记 noindex。

#### Scenario: 内容审查
- **WHEN** 复核下载文案、案例和平台支持
- **THEN** 每个可用声明可对应发布资料与验收，不出现保证求职结果、保证不封号、虚构用户评价或技术术语堆砌。

### Requirement: WEB-14 站点交付与发布边界

交付 MUST 使用明确白名单暂存站点文件，不上传整个项目根目录。发布工作流 MUST 仅允许人工触发，固定 GitHub 仓库、Pages 项目和获批的完整提交；不得用普通 push、PR 或定时任务发布。Gitee 版本同步和生产发布 MUST 分别留证。

#### Scenario: 发布包检查
- **WHEN** 在本地准备站点上传目录
- **THEN** 只有 design 列明的站点文件；不存在 PRD、Spec、协作指令、参考图、原型、求职包配置或私人资料；二进制软件安装包不混入 Pages 网站资源。

#### Scenario: 未获发布授权
- **WHEN** 仅完成网站实施 / 本地校验，或 workflow 的授权目标、提交、项目不匹配
- **THEN** 不触发上传、创建云资源或修改域名；说明缺项并保留可审阅的本地结果。

#### Scenario: 获准发布后验证
- **WHEN** 独立发布授权齐备并执行发布
- **THEN** 记录提交、Actions run、Pages deployment ID、不可变 URL、正式域名和首页 / 教程 / 404 实际结果；只有 HTTP 200 或上传成功不能替代页面验收。
