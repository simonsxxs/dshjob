## Why

现有 `index.html` 只有建设中提示，AI 新手无法判断项目能做什么、从哪里获取、下载后如何开始，也找不到连续的帮助路径。首版需将免费项目介绍、四种使用方式、教程和作者联系入口连成完整流程，并落地已认可的浅色粒子光束风格。

## What Changes

- 用完整首页替换占位页：首屏、能力、演示、四步概览、获取工具、FAQ、联系与页脚。
- 增加独立教程 `guide.html`，以“软件下载 / Agent 智能体 / Skill 技能包 / MCP 工具接入”四个章节说明适用人群、前置条件和操作位置。
- 下载区固定四入口顺序，软件下载排第一；软件条目按已确认的系统、架构和版本提供真实安装包入口，尚未提供时展示准备状态。
- Gitee / GitHub 仓库入口与安装包下载入口分别命名；保留备用来源与求助出口。
- 实现浅雾蓝背景、白色卡片、深蓝文字、蓝青色光束；桌面轻微响应鼠标，手机降档，支持暂停、减少动态效果与静态回退。
- 实现移动菜单、演示切换、FAQ、复制与图片失败反馈；所有关键文字、链接与教程直接存在于 HTML。
- 使用用户提供的微信原图与文字账号 `simonsxxs`，在教程和首页均可找到 simon。
- 准备最小 404 页面、搜索元数据、站点文件白名单校验及人工发布工作流；网站保持无框架、无前端构建。

## Capabilities

### New Capabilities

- `static-website`：面向 AI 新手的静态项目官网，涵盖内容导航、四方式获取、教程、演示、联系、动效、降级和交付边界。

### Modified Capabilities

无。项目尚无既有 OpenSpec 能力基线；本变更是首版规格。

## Impact

预计实施路径详见 [design.md](design.md) 第 1 节：`index.html`、`guide.html`、`404.html`、`assets/` 内明确的站点资源、`robots.txt`、`sitemap.xml`、站点校验 / 打包脚本、手动发布工作流及必要验证记录。无 API、数据库或招聘账号接口变更；不增加访客端 npm 依赖。

不包含软件本体、安装器、自动更新服务、Agent 执行器、任何兄弟项目或共享账号状态的修改。网站点击仅导航、复制或切换 UI；下载和安装在用户设备 / 仓库发布页完成。
